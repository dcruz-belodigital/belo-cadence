# Docs

## The product name stays "Cadence" in every language
"Cadence" is a brand name, not a word to translate. Portuguese catalogues and docs keep it in English — `navigation.groups.cadence` is `Cadence` in `lang/pt` as well as `lang/en`, and the docs write the navigation path as **Cadence → …**, never **Cadência → …**. Same for "Belo Cadence", which is already left alone everywhere.

The only allowed `cadência` is the ordinary noun in running prose, where English says "cadence" meaning rhythm (e.g. "lembretes com uma cadência mensal ou anual"). If it names a screen or the product, it is `Cadence`.
